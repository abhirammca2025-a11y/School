# 🏫 SAI English Medium School Website

A responsive and modern school website developed using **HTML, CSS, and JavaScript**. The website provides information about the school, academics, facilities, activities, admissions, events, testimonials, and contact details.

## 🌐 Project Overview

The **SAI English Medium School Website** is designed to provide students, parents, and visitors with an easy-to-use online platform to explore school information and stay updated with important announcements and activities.

## ✨ Features

* 🏠 **Home Page** – Welcome section with school introduction
* 📢 **Latest News** – Displays important school announcements
* 📚 **Academics** – Pre-Primary, Primary, High School, and Higher Secondary sections
* 🎓 **Admissions** – Information about the 2026–2027 admission process
* 👨‍🏫 **Principal's Message** – Message from the school principal
* 🏫 **School Facilities** – Library, Science Lab, Computer Lab, and Sports
* 📊 **School Statistics** – Students, teachers, years of excellence, and achievements
* 🎉 **Upcoming Events** – Sports Day, Science Exhibition, and Arts Festival
* 💬 **Testimonials** – Feedback from parents
* 🖼️ **Gallery** – School activities and event images
* 📞 **Contact Section** – Phone, email, and address information
* 📱 **Responsive Design** – Designed to work across different screen sizes
* 🔽 **Dropdown Navigation** – Academics and Activities menus
* ⭐ **Font Awesome Icons** – Used for visual enhancement

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Website interactions
* **Font Awesome** – Icons

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/sai-english-medium-school.git
```

2. Open the project folder.

3. Make sure the `images` folder contains all required images.

4. Open `index.html` in your web browser.

For a better development experience, you can use **Visual Studio Code** with the **Live Server** extension.
